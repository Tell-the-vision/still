All implementation should be grounded in https://github.com/Tell-the-vision/PRD/blob/main/docs/SPEC.md. Ambiguous questions should be raised as issues.

Prioritize code clarity over performance.

Always modify the server and client together in one commit, including proper test cases that use `next/experimental/testmode/playwright` and prove the feature is reachable by a user.

For UI work, images of the completed work should be attached to the PR.

Branch names should follow the `<service>/<content>` convention.
